# 撮影用ダミーデータ（demo-data）

動画・スクリーンショット撮影用のダミーデータ一式。旧 `?demo=1` デモ環境の代替で、
**本番URL＋撮影用ブラウザプロファイル＋Clavis用別Googleアカウント** の運用で使う。

## 使い方

1. （推奨）撮影前に日付をリフレッシュする:

   ```
   python demo-data/generate_demo_data.py
   ```

   在留期限「45日前」「15日前」などのアラート表示が今日基準で再計算される。

2. 撮影用ブラウザプロファイルで本番URL（app.html）を開く。
3. 事務所設定 → 💾 バックアップ → **📥 JSONから復元** で `clavis-demo-data.json` を読み込む。
4. `office.license_key` は空にしてあるので、ポイポイ式などAI機能を撮る場合は
   インポート後にライセンスキーを再設定する（ライセンスとクライアントデータは非連動）。

## 中身

- クライアント9名: 技能（THAPA RAM）、家族滞在（扶養関係あり）、技人国、永住者、
  特定技能1号（期限15日前アラート）、留学、COE申請中（来日前）、帰国済み、一般法人
- 案件7件: 書類収集中／申請中／相談中／許可／COE／一般（会社設立）
- 請求6件: まとめ請求（夫婦同時申請）、入金済、一部入金、見積（見込案件）

## 注意

- 全データは架空。実在の人物・企業とは無関係。
- インポートは本番と同じ `migrateData` 経路を通るため、将来のデータ構造変更にも
  実データ同様に自動追従する。JSONを手で最新構造に追従させる必要はない。
- 実データのプロファイルでは絶対にインポートしないこと（全データが上書きされる）。
